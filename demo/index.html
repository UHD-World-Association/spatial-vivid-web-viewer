UWA Spatial Vivid Web Viewer
This Three.js-based reference viewer loads UWA Spatial Vivid scenes, based on 3D Gaussian Splatting, directly in the browser. UWA scenes are packaged as .glb assets and use the available ASTC, BC, or CPU texture path selected for this browser.

Choose one of the bundled UWA scenes below, or use the local-file viewer for .glb, .ply, .ksplat, and .splat files.
